# ShopSphere Deployment

This project is split into two deployable parts:

- **Backend:** Render Web Service from `backend/`
- **Frontend:** Vercel project with Root Directory set to `frontend/`
- **Database:** MongoDB Atlas

## 1. Render backend

Use the repository `Fida419/ShopSphere-Ecommerce` and the included `render.yaml` Blueprint.

Required environment variables:

- `MONGO_URI` = MongoDB Atlas connection string
- `JWT_SECRET` = generated by Render
- `CLIENT_URL` = the final Vercel frontend URL

The backend health endpoint is `/api/health`.

## 2. Vercel frontend

Create/import the same GitHub repository in Vercel and set:

- Root Directory: `frontend`
- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`

Set this environment variable in Vercel:

- `VITE_API_URL` = `https://YOUR-RENDER-SERVICE.onrender.com/api`

The included `frontend/vercel.json` handles React Router history fallbacks.

## 3. Final connection

After Vercel gives the frontend URL, set the Render backend variable:

`CLIENT_URL=https://YOUR-VERCEL-DOMAIN`

Then redeploy the Render service if needed.

## Security

Never commit `.env`, MongoDB credentials, JWT secrets, or payment secrets. The repository already ignores `.env` files.
